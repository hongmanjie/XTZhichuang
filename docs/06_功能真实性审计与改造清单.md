# 功能真实性审计与改造清单

> 2026-10-29 更新：下方表格记录的是实施前的审计快照，部分问题已经修复或暂时关闭。当前状态、实际测试和剩余限制以 [实施记录与 Linux 部署说明](./07_实施记录与Linux部署说明.md) 为准。

审计日期：2026-10-28。范围为当前项目的前端页面、15 个后端路由文件、AI 服务和初始化数据，并核对当前账号可见的 ModelGate 视频任务。静态扫描发现约 238 个路由声明；本文件列出已确认的主要问题，不表示每个接口都已逐项完成运行验收。

本文件是改造计划。当前系统仍存在下述模拟和演示功能，尚未完成全站真实化。本次未重新运行种子脚本、未删除数据，也没有提交新的图片、视频或 TTS 任务。

## 1. 总原则

1. 生产界面中的数据必须来自真实用户操作、真实模型产物或经授权的外部系统，能说明来源。
2. 真实能力失败时显示失败和原因，保留可恢复任务；不允许返回示例视频、固定分析或虚构数据并标为成功。
3. 不能马上接入外部平台或模型时，明确显示“未接通”，完成依赖接入后再启用；最终目标是将需要保留的功能全部做实。
4. 固定选项、可编辑模板和用户明确知道的示例素材不等同于假业务数据。示例只放明确标识的演示区，不混进真实资产、真实报表或成功任务。
5. 现有 SQLite 中可能同时有初始化演示记录和用户创建的数据。必须先一致性备份，按来源、文件和用户核实，再隔离或清理演示数据，禁止一键清空。

## 3. 数据来源审计

- [seed.js](../server/src/seed.js) 会删除多张业务表后插入演示用户、素材、脚本、爆款和广告数据，不可对正在使用的数据库直接重跑。
- 数据罗盘也有单独的预置数据集；旧数据库不能仅凭记录名称判断真假。
- 前端页面中的随机趋势、默认大数和固定授权状态必须清除；没有真实数据时显示空状态。
- 已生成的作品需要记录来源：用户上传、真实模型任务、示例/演示、第三方授权素材等。历史记录若无法确认来源，标为“来源待核对”，不自动当成真实模型产物。
- 保留现有用户最近创建和修改的脚本、素材、作品及日志。演示数据迁移或清理应先生成备份和待处理清单，确认无误后执行。

## 4. 依赖和实施次序

1. **停止假成功与保护数据**：梳理并关闭生产路径里的固定成功和模拟支付；真实失败返回错误；先做数据备份与来源清单。实际实施时保证现有真实脚本和素材不丢失。
2. **建立真实任务基础**：统一真实状态、幂等、队列、费用预留和失败恢复，修复 H3 参数与字幕依赖。
3. **先打通已有能力**：真实 H3 文本/首尾帧、已有 ASR/OCR、现有文件存储和 IndexTTS 适配；由真实任务和产物验证结果。
4. **补齐缺失模型**：商品图编辑、视频理解、真实超分、视频去字、音轨分离和口型同步需核对模型、部署资源和效果，不能通过改提示词替代。
5. **接入外部业务**：广告授权、数据同步、支付、返佣、提现和平台发布需要相应的真实账号、接口及授权；无来源时不伪造数据或成功。
6. **逐项验收**：每个功能记录输入、真实上游、任务编号、结果文件/业务记录、失败状态和用户可见提示；包括页面、接口、后台任务和数据的完整链路。

## 5. 当前 MiniMax-H3：已核实范围

根据 2026-10-26 的 [ModelGate 接口手册](../ModelGate_8模型统一接口调用手册_20261026.pdf)，当前网关接口设计支持四种输入：

| 模式 | 输入 |
| --- | --- |
| t2av | 文字 |
| i2av | 文字 + 首帧图片 |
| l2av | 文字 + 尾帧图片 |
| fl2av | 文字 + 首帧图片 + 尾帧图片 |

手册记录四种模式当时均完成过真实生成及 MP4 下载，示例结果约 5.175 秒；当前项目页面主要接了文字和首帧，尾帧/首尾帧仍要接入用户界面与业务流程。手册中的参考图为 PNG/JPEG/WebP 的图片内容，每张上限 10 MiB。当前已核实的网关契约不包括输入参考视频或参考音频，不应把模型其他版本的能力当作本接口已支持。

| 项目 | 已知范围或验证 |
| --- | --- |
| 返回 | 单个 MP4，可包含 H3 生成的音频；202 后需要查询任务完成和下载。 |
| 帧率/时长 | 手册为 24 fps，合法帧数 124、141、158、175、192、209、226，约 5.17–9.42 秒；真实输出以媒体探测为准。 |
| 参数校验 | 高、宽各 256–2048，且为 32 的倍数；顺序为高、宽。这不等于每种尺寸都已证明可稳定生成。 |
| 已有真实样本 | 本次只读探测已有成功任务：512×896 / 5.175 秒、960×544 / 5.175 秒、1280×736 / 7.3 秒；均为 24 fps 且有音轨。 |
| 更高分辨率 | XT 工作台研究记录曾测试 1376×768 / 5.175 秒；该记录对应其当时的 H3 部署，是否与当前网关底层完全相同需要核实。未验证当前网关的原生 1080p、2K 或 4K 成片。 |

本次只读查询到当前账号的 43 条历史视频任务：24 条成功、17 条失败、2 条取消。失败状态码中包括 6 条上游离线过期、5 条上游失败、5 条任务恢复过期和 1 条队列等待过期。其中请求尺寸为高 736、宽 1280 的记录有成功和失败。任务来源、时间、并发和参数不一致，这些记录不能作为不同分辨率可靠性的对照实验；状态码也不足以确定根因。应结合网关日志、GPU 资源和受控测试排查，不应只依据可提交尺寸就承诺画质或稳定性。

网关模型列表当前能看到 MiniMax-H3，并包含非零计价配置字段；实际账单单位与用户成本仍需按网关规则核对，不能仅根据项目内“免费”字样承诺免费。

## 6. 验收口径

- 逐功能核对“用户输入 → 后端 → 真实上游或计算 → 产物/真实业务结果 → 页面显示”；记录能够回放的样例和证据。
- 故障时检查真实错误、重试、资源占用和点数账本；不允许用示例图、演示视频、随机数据或空返回冒充成功。
- 进行小规模并发、进程重启和断网恢复测试，核验请求去重及数据不丢失。
- 对需要外部授权的支付、平台 OAuth、发布和投放数据，使用对应平台的测试环境和真实授权验收；没接入时在页面清楚说明。
- 用户端保持简洁：长视频后台自动分镜，配音/换音/口型合并为一个页面；真实性改造不以新增复杂画布为前提。
