# Linux 合并与测试记录（2026-10-31）

## 合并范围

以同事的 GitLab main 57ad20e 为基础，合入此前本机尚未包含的语音、字幕、三秒开场、视频增强和相关任务引擎改动，并保留子路径、登录与权限逻辑。独立开发环境使用单独的 Compose 项目、数据库、上传卷和 Elasticsearch。

## 自动测试

- Linux Node 22，前端以 /xtzc/ 为基础路径构建成功。
- 后端自动测试覆盖分段规划、媒体处理、字幕、配音、权限、任务恢复、字幕文字检查及索引安全。自动测试使用隔离数据库与模拟模型网关；其中 FFmpeg 处理的是实际生成的测试媒体。
- 额外通过 HTTP 验证管理员与创作者权限、未登录媒体访问、其他用户媒体隔离及退出时 Cookie 清除。

## 真实输入和结果

| 功能 | 输入 | 实际结果及限制 |
| --- | --- | --- |
| 三秒开场 | 文本描述白色杯子及影棚，选择 540P | 模型生成并截取 3 秒，544×960；抽帧发现模型自行添加文字和标志，画面质量未达到可直接商用的结论。 |
| 画质增强 | 272×480、1 秒、有音轨的测试视频 | SeedVR2 返回 416×720、1 秒、有音轨；模型可能改写细节和文字。 |
| 视频拼接 | 两段相同的 5.176 秒测试视频 | FFmpeg 输出约 10.353 秒、544×960、有音轨的视频；不包含自动选镜。 |
| 字幕和遮挡 | 5.176 秒带音轨视频、人工字幕及底部 20% 黑条 | 输出同尺寸视频并保留音轨；黑条遮挡原画面，不是无痕去字。 |
| 语音识别 | 含合成语音的 5.176 秒视频 | FunASR 识别为“欢迎来到小店”，时间为模型片段及估算，仍需校对。 |
| 音色和配音 | 由合成语音提取的参考音频和测试文案 | 成功上传音色，经 ModelGate IndexTTS 合成并替换视频音轨。一次数字人测试中合成语音约 7.5 秒，超过 5.2 秒画面，系统提示失败并保留原画面；现阶段不能保证每次语音时长都合适。 |

| 口型同步 | 含单人正面画面的 5.175 秒视频、测试音色和文本 | 直连 LatentSync，返回约 5.2 秒、544×960、25 帧、有音轨的视频；一次 H3→IndexTTS→LatentSync 数字人链路也成功。口型质量仍需观看核验；原画面自带文字不会被移除。 |
| 多模态检索 | 无商品关键词的白杯图片、人物图片和“白色杯子”搜索词 | 直连多模态向量模型并写入独立 ES 索引，白杯排在人物之前；这是小样本技术验证，并不代表全部场景检索准确。 |
| 画面文字检查与字幕 | 含两行旧字幕的视频；另一个没有明显画面文字的人物视频 | 前者识别到已有字幕并暂停自动叠加；后者通过抽帧检查后，真实配音并叠加“欢迎光临。”，抽查五帧出现一行字幕、没有发现双行字幕。本次未开启口型同步。采样可能漏检或误判，不能替代观看成片。 |

素材和脚本等业务数据保存在独立数据库；ES 用于关键词及向量检索。测试 ES 数据存放在独立目录，测试账号、上传素材、模型配置和密钥均不提交。

## 尚待继续

- 口型同步已直连测试服务，仍需使用用户实际视频验收口型质量；网关适配协议尚待提供。
- 多模态向量已直连原模型并验证小样本；后续网关开放图片接口后仍需适配，业务检索质量需更大样本验收。
- 长视频此前有技术样片，本次合并后的自动测试使用模拟网关；真实商品、长时间连续性、并发和质量仍需专项验收。
- 模型可能自行生成字幕、角标或乱码。提示词和抽帧 OCR 不能保证成片无文字；已有硬字幕不会自动去除，字幕遮挡会遮住原画面，不是无痕修复。
- 短文案生成的配音也可能长于视频，需进一步完善先生成语音再规划画面时长的流程。
- 浏览器登录页可打开，完整页面点击自动化没有完成；实际生产功能仍需逐项业务测试。
